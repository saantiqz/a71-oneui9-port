# Features and Compatibility

**Device:** Samsung Galaxy A71 4G (SM-A715F)

**Android version:** Android 17

**ROM:** One UI 9

**Donor device:** Samsung Galaxy S23

**Kernel:** Paradigm 4.14 with FOD support

## Working Features

### System
- Boots successfully.
- SELinux enforcing.
- File-based encryption.
- PIN unlock after reboot.
- Samsung setup and initial configuration.
- Port information in Settings.

### Connectivity
- Wi-Fi.
- Bluetooth.
- Mobile data.
- Phone calls.
- Access Point Names.
- Data Roaming.
- NFC.

### Biometrics
- Optical under-display fingerprint.
- Face unlock.

### Camera and Media
- Photo capture.
- Video recording with sound.
- Camera mode switching.
- Night and HDR scenes.
- 4K video playback.

### Samsung Features
- Samsung DeX.
- Galaxy AI.
- Now Brief.
- Personal Intelligence.
- Eye Comfort Shield.

### Hardware
- Speaker.
- Microphone.
- Vibration.
- Flashlight.
- Charging.
- Sensors.
- Auto-rotate.
- A71 thermal profile.

## Known Issues

- Now Nudge is unavailable because it requires SSCO, which the A71 does not support.
- Black areas appear slightly brown on the current test device. Other panels remain untested.
- 5 GHz Wi-Fi idle wake behavior remains untested.
- Face unlock displays a harmless rotation warning.

## Installation Requirements

- Samsung Galaxy A71 4G (SM-A715F).
- Compatible TWRP recovery.
- Included FOD Prime Kernel.
- Backup of personal data.

**Important:** Coming from One UI 8.5 or another ROM requires Format Data. Internal storage will be erased.

Do not use a kernel without the required FOD patch if you need fingerprint functionality.
